# Sujith R & Swathy T — Romantic Storybook Invitation

A responsive static wedding reception invitation website.

## Preview
Open `index.html` in a browser. Internet is required for the Google Fonts import; all illustration assets are included locally.

## Deploy
Upload the contents of this folder to your `groom-invitation` branch (or connect the branch to a Cloudflare Pages project). The site is static and requires no build command; set the output directory to `/` or the repository root for a branch containing these files.
